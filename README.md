# SWTCWW - 'Star Wars: The Clone Wars' Wisdom

Recreating the opening quotes from one of my favorite shows, *Star Wars: The Clone Wars* :)

This project is meant to be a convenient way for fans like me to revisit the iconic opening quotes and remember the show, while hopefully sharing some of its wisdom with people who haven't watched it yet.

## Details

I haven't had the time to precisely reverse-engineer the opening quotes, so instead, I did some research and used tools to approximate their appearance.

### Font

I couldn't find any reliable information about the typeface used for *The Clone Wars'* opening quotes, so I turned to the films' opening line, "A long time ago in a galaxy far, far away....", because of its similarity. I came across several possible typefaces, including Trade Gothic, News Gothic, and Franklin Gothic, with Trade Gothic and Franklin Gothic being close visual matches to the show's opening quotes.

I ended up going with Libre Franklin, an open-source interpretation of Franklin Gothic (also similar to Trade Gothic), because I'm broke. I use its regular weight (400) to match the lettering as closely as possible. The font size scales with the device's screen size to maintain similar proportions across devices.

I'm no typography *connoisseur*, so this was more of an informed visual guess.

### Text color

For the blue lettering, I used the eyedropper in the browser's DevTools panel on an actual screenshot from the show to try to match the color as closely as possible. The quotes use `#1379a6`, my screenshot-based approximation of the original blue.

### Background

I used the same eyedropper on the screenshot's black background. The site uses `#000000` to recreate it, again based on that screenshot rather than an official color specification.
